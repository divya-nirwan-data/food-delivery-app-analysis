# 🍔 Food Delivery App Data Analysis Project

## 📌 Project Overview
This project analyzes food delivery app data to understand customer behavior, order trends, revenue performance, and delivery efficiency.

The goal is to extract business insights that can help improve customer satisfaction, delivery speed, and overall profitability.

---

## 🎯 Problem Statement
The food delivery company wants to:
- Analyze order trends
- Identify top-performing restaurants
- Understand customer ordering patterns
- Improve delivery time efficiency
- Increase overall revenue

---

## 🛠 Tools Used
- SQL (Data Analysis)
- Power BI (Dashboard & Visualization)
- Excel / Power Query (Data Cleaning)

---

## 📊 Key KPIs Analyzed
- Total Orders
- Total Revenue
- Average Order Value
- Average Delivery Time
- Top Restaurants
- Customer Retention

---

## 📈 Project Workflow

### 1️⃣ Data Cleaning
- Removed null values
- Corrected date formats
- Handled duplicate entries
- Standardized restaurant & city names

### 2️⃣ SQL Analysis
- Revenue by city
- Monthly growth rate
- Top 5 restaurants
- Order frequency per customer
- Delivery performance analysis

### 3️⃣ Power BI Dashboard
Created interactive dashboard showing:
- Revenue Trends
- Order Volume Analysis
- City-wise Performance
- Delivery Time Insights
- Top Categories

---

## 💡 Key Insights
- Certain cities contribute highest revenue
- Few restaurants generate majority of revenue
- Delivery delays impact customer ratings

---

## 🚀 Business Recommendations
- Offer promotions during low-order hours
- Improve delivery operations in slow zones
- Provide loyalty rewards to frequent customers
- Optimize restaurant partnerships
